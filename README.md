# Anime Player для iOS

Нативное iOS-приложение на SwiftUI с собственным интерфейсом, каталогом-провайдером и воспроизведением через AVPlayer. Откройте `AnimeStreamPlayer.xcodeproj` в Xcode; минимальная версия iOS — 16.

## Уже реализовано

- Нижняя навигация: «Лента», «Библиотека», «Настройки».
- Поиск по каталогу, обновление ленты вручную и расположение карточек: 2 × 2, 3 × 2 или список.
- Карточка тайтла сначала показывает описание; затем можно открыть озвучки с количеством серий и список серий.
- Статусы библиотеки «Смотрю», «Просмотрено», «Планирую», «Брошено» пользователь задаёт сам; открытые и просмотренные серии сохраняются и не добавляют тайтл в библиотеку автоматически.
- Прогресс просмотра сохраняется на устройстве. При повторном открытии серии можно продолжить с сохранённого места или начать сначала.
- Настройки темы, нескольких готовых акцентных цветов или своего цвета через ColorPicker, разрешения на уведомления о новых сериях, скорости по умолчанию (0,75×–3×) и временного окна для кнопки пропуска опенинга.
- Кастомный плеер: шкала времени, пауза/воспроизведение, перемотка двойным нажатием и аудио-/субтитровые дорожки, если их предоставляет поток. После пяти быстрых двойных нажатий размер шага увеличивается с 10 до 20 секунд.
- Настройка «Только источники без рекламы» включена по умолчанию и принимает поток лишь если поставщик явно помечает его как без рекламных вставок. Неизвестные и помеченные рекламными потоки блокируются; фильтр можно отключить для доверенных ссылок. Подтверждение поставщика не позволяет независимо проверить рекламные вставки внутри самого видеопотока.
- Ненавязчивая кнопка вручную пропускает 90 секунд только в настроенном временном окне начала серии и скрывается, если до конца осталось меньше 90 секунд.
- Для проверки плеера в настройках есть отдельный экран для разрешённой HTTPS-ссылки; полный URL не сохраняется в истории.
- Текущие тайтлы, описания, постеры и поиск подключены к публичному AniList GraphQL API. Счётчик вышедших серий оценивается по следующему номеру в расписании AniList.
- `AnimeStreamProvider` отделяет каталог и поиск от видеосервиса: к нему можно подключить легальный источник озвучек, серий и потоков.

## Ограничения

Каталог и глобальный поиск используют публичный [AniList](https://anilist.co/) GraphQL API; доступность и точность расписания зависят от него. Это международное расписание, а не гарантия даты доступности серии в России. AniList предоставляет метаданные, но **не предоставляет озвучки или видеопотоки**. Поэтому реальные варианты озвучки, списки серий для воспроизведения и стриминг появятся только после подключения легального видеопоставщика. Мы не подменяем их выдуманным списком.

Уведомления сейчас сохраняют пользовательское предпочтение и запрашивают системное разрешение iOS. Фактическая доставка уведомлений о премьерах появится только вместе с источником обновлений и его механизмом доставки. Аналогично, автопереход на следующую серию и автоматический пропуск эндинга не включены: для безопасной работы нужны точные метаданные серий и таймингов от поставщика.

Чтобы подключить реальные аниме и озвучки, нужен поставщик, который официально разрешает приложению получать URL потока для воспроизведения. Не добавляйте парсинг закрытых сайтов, приватные API или обход авторизации/геоблокировок. Бесплатность, выбор озвучек и доступность в России зависят от условий конкретного поставщика.

Пока видеопоставщик не подключён, приложение не может гарантировать потоки без рекламы. Новый адаптер поставщика должен указывать политику рекламы для каждого выданного потока; режим без рекламы отклоняет любой поток, не помеченный поставщиком как свободный от рекламы.

## Сборка IPA для TrollStore из Windows

В репозитории есть workflow `.github/workflows/build-trollstore-ipa.yml`, который бесплатно собирает IPA на macOS runner GitHub Actions без сертификата Apple:

1. Загрузи проект в GitHub. Для стандартного бесплатного macOS runner репозиторий должен быть публичным; для приватного могут применяться лимиты GitHub Actions.
2. На GitHub открой **Actions → Build IPA for TrollStore → Run workflow**.
3. После успешной сборки скачай `AnimeStreamPlayer.ipa` в разделе **Artifacts** запуска workflow.
4. Передай IPA на iPhone и открой его в TrollStore для установки.

TrollStore работает только на поддерживаемых версиях iOS; официальный проект указывает диапазон от iOS 14.0 beta 2 до iOS 16.6.1, отдельные сборки 16.7 RC и iOS 17.0. Проверь совместимость конкретной версии iOS своего устройства в [официальном README TrollStore](https://github.com/opa334/TrollStore). Сборка из workflow предназначена для установки через TrollStore, а не для App Store.

## Проверка

Сборка и запуск требуют macOS, Xcode и iOS Simulator либо устройство. Среда разработки проекта сейчас Windows, поэтому полноценную iOS-сборку здесь выполнить нельзя.
